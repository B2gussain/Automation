# Lead Qualification AI Agent

## 1. Project Overview

The Lead Qualification AI Agent is an AI-powered system that interacts with potential customers, collects important project information, qualifies the lead, calculates a lead score, stores the lead in a database, and notifies the business/sales team.

The goal is to simulate a real-world business automation that can be used by agencies, software companies, freelancers, and service businesses.

---

# 2. Project Goals

The system should:

- Talk naturally with potential customers.
- Understand what service the customer needs.
- Collect required lead information.
- Ask follow-up questions when information is missing.
- Determine whether the lead is qualified.
- Calculate a lead score.
- Store lead information in MongoDB.
- Allow the AI Agent to interact with backend tools/APIs.
- Eventually send notifications to the sales team.
- Eventually integrate with n8n and external services.

# 6. Lead Qualification

The AI should determine whether a lead is worth sending to the sales team.

## Qualification Factors

### Budget

| Budget            | Score |
| ----------------- | ----: |
| < ₹20,000         |     1 |
| ₹20,000–₹50,000   |     2 |
| ₹50,000–₹1,00,000 |     3 |
| > ₹1,00,000       |     4 |

### Timeline

| Timeline                 | Score |
| ------------------------ | ----: |
| More than 6 months       |     1 |
| 3–6 months               |     2 |
| 1–3 months               |     3 |
| Immediately / This month |     4 |

### Project Clarity

| Description        | Score |
| ------------------ | ----: |
| Very unclear       |     1 |
| Somewhat clear     |     2 |
| Clear requirements |     3 |

## Lead Score

Maximum score:

```text
4 + 4 + 3 = 11
```

Qualification:

```text
8–11  → Qualified
5–7   → Potential
1–4   → Low Priority
```

The score should be generated by the backend/business logic rather than blindly trusting the AI.

# 7. AI Agent Responsibilities

The AI Agent should:

1. Understand the customer's request.
2. Identify the required service.
3. Ask for missing information.
4. Avoid asking for information that has already been provided.
5. Ask questions naturally instead of asking everything at once.
6. Determine when enough information has been collected.
7. Call the appropriate backend tool.
8. Never invent customer information.
9. Never invent prices or company policies.
10. Tell the customer when the lead has been submitted successfully.

# 18. AI Conversation Rules

The AI should not ask unnecessary questions.

For example, if the user says:

> I need an ecommerce website, my budget is ₹1 lakh and I want it next month.

The AI already knows:

```text
service = Website Development
projectDescription = Ecommerce website
budget = ₹100000
timeline = Next month
```

It should only ask for the missing information.

For example:

> Great! Could you share your name and email so I can submit your project details to our team?

---

# 19. Important AI Rules

The AI must:

- Never invent a budget.
- Never invent an email.
- Never invent a phone number.
- Never claim that a lead was saved unless the tool confirms it.
- Never claim that the sales team was notified unless the tool confirms it.
- Never change the customer's information.
- Never save incomplete required information.
- Never calculate the final lead score itself if the backend scoring tool is available.
- Ask for confirmation before submitting the final lead if necessary.
